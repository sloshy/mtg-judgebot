import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid stagger>
  <Card title="Never guesses" icon="approve-check">
    Nicknames like "bob" and "goyf" resolve to cards through a fixed order of lookups. A name
    that could mean several cards becomes a "did you mean…?" prompt, never a guess.
  </Card>
  <Card title="Citations are validated" icon="magnifier">
    A quote has to appear verbatim in the rule, ruling or Oracle text it names. A citation
    that fails is rejected and the model is asked again. An answer with no citation never
    ships.
  </Card>
  <Card title="Spend is capped" icon="seti:lock">
    Every model call is metered against a spend cap, per process or per day or month. The
    worst-case cost is reserved before each call. The anonymous web page is also rate
    limited per IP.
  </Card>
  <Card title="Models are configuration" icon="setting">
    Anthropic direct, through a proxy, on AWS or Vertex, or any OpenAI-compatible server
    including a local Ollama. All of it is set in `judge.toml`, with no code changes.
  </Card>
</CardGrid>

## Self-hosting

Each community runs its own judgebot, so the spend cap, the judge role and the Discord
application are yours. The web page and the command line work before you have a bot
token. Read
[what the judge is](./start-here/what-it-is/), or go straight to
[requirements and first run](./self-hosting/first-run/).
