## Yours to run

There is no bot to invite. A judgebot is meant to be run by the community that uses it, so
that the spend cap, the judge role and the Discord application are yours — and nothing in
the pipeline depends on Discord, so the web page and the command line work before you have
a bot token. Read [what the judge is](./start-here/what-it-is/), or go straight to
[requirements and first run](./self-hosting/first-run/).
